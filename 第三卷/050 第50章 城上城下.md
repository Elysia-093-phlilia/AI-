# 第50章 城上城下

**贞观十九年·八月**

围城进了第二个月，城上城下，都磨疲了。

白天是箭和土山，夜里反而是安静的。安静到什么程度呢——城下咳嗽一声，城头听得见；城头换岗的脚步声，城下守夜的老兵也数得清。

有一夜，城里飘下来一段唱。听不懂词，调子又低又长，一句一顿，像哭又不像哭。

"唱的什么？"新兵问。

"丧歌。"守夜的老兵说，"城里也在死人。他们给自己人送行呢。"

新兵听着听着，忽然眼圈红了。老兵瞪他："哭什么，又不是你娘的丧。"

"不是。"新兵抹了把脸，"就是想起来，俺们营埋的那几个，连首歌都没给唱。"

那夜之后，营里悄悄兴了个不成文的规矩：夜里收殓，抬尸出营的时辰，吹角的人会把角吹得又低又缓——不懂的人听是号角，懂的人听，是送行。

城上城下的丧歌和角声，隔着一道壕、一堵墙，各自给各自的人送行。谁也没跟谁约过。

陆晏清听说这段，是在粮台的账房里。他记了一笔："八月十七夜，城上唱丧。"

写完他又觉得这五个字太干，坐了半夜，把当日城中送饭的账一笔笔核完才睡。

八月中，辽东城缴获的官档解到了大营——六月破城时从府库里抢出来的，几箱湿透的前朝旧纸。粮台领了晾晒誊录的差，陆晏清一页一页地翻。

翻到第三箱，他的手停了。

前朝大业七年的征辽兵册。

泛黄的纸页上，一列列名字，墨迹深深浅浅。名字后头，有的注一个"殁"字，有的注一个"亡"字，更多的，什么都没注。

没注的那些，要么还活着——要么，是死了都没人管他们死没活。

他又翻到另一册：大业八年的抚恤簿。发到辽东州仓的抚恤记录，停在大业八年的秋天。再往后，纸就是白的了——那一年之后，天下就乱了，仓空了，册子也跟人一起流离。

"折角的账。"陆晏清坐在档箱边，忽然想起死生簿扉页那行字。

账上有名字，账外有真人——折角，就是给这笔账留一个"没完"。

他连夜写了道条陈，报行辕：凡前朝征辽阵亡无主之名，许降卒、民夫、各色人等**认领**——录其名、其籍、其亲在何处，战后按名补恤。行辕这次批得爽快，只添了一句："粮台自办，钱粮战后清算。"

认领簿立起来的第三天，来了个人。

降卒营的，五十上下，背也有点驼，进门先搓手，搓了半天，才说自己是来"认个名"的。

"我叫吴大有。"他说，"安市城里人。三十年前……不是，三十多年前，俺不是这儿的人。俺是幽州的。"

大业八年，他被征进前隋的兵，十六岁，抬粮的民夫。辽东城下兵败，队伍散了，他跑错了方向——跑进了高句丽的地界，被拿住，一留就是三十三年。娶了妻，生了子，乡音磨得只剩下尾音。

"俺有个兄弟，"吴大有的手一直在抖，"吴大安。俺爹给起的名，说平安的安。他跟俺一起被征来的——不是，他是先来的，俺是后来寻他的。大业八年二月，辽东城下，就那么两三天……兵败了，俺们跑散了。俺活下来，他没信儿。"

他抬头看陆晏清，眼睛里全是不敢：

"大人，俺这三十三年，不敢打听。俺怕——怕册子上给他记的是'逃'。逃兵的家里，是要连坐的。俺爹娘到死，都不知道该给他上坟，还是给他烧纸。"

陆晏清翻档的手很快。

大业七年的兵册，吴大安，幽州人——在。

名字后头一个字：殁。旁边一行小注：**殁于王事，辽东城下。**

他再翻大业八年的抚恤簿：吴大安的抚恤，注着"发幽州"——发到没发，册上没有下文。那一年，幽州仓和整个天下一起，乱没了。

"吴大有。"陆晏清把两页档并排摆在他面前，"你看清楚。你兄弟的名字，前朝记的是'殁于王事'——这四个字，是国家欠的账，不是你欠的。"

吴大有凑近了，一个字一个字地认。认到"殁于王事"，这五十岁的汉子忽然蹲下去，把脸埋进两只手里，肩膀一耸一耸，半天，发出一声压了几十年的嚎。

他嚎的不是兄弟死了。是兄弟死得清白。

陆晏清提笔，在认领簿上端端正正写：

"吴大安，幽州人，大业八年二月，殁于辽东城下。领恤人：吴大有，兄，现居安市——战后按名补给其侄。"

写完，他从自己当月的俸绢里抽出两匹，一并推过去。

"朝廷的账，战后清算。"他说，"今晚这笔，我垫。"

吴大有捧着绢出了营门。走出去几步，他忽然回身，朝西南方向跪下去，结结实实磕了三个头。

一个给爹娘。

一个给兄弟。

第三个，他没说给谁。陆晏清在营门里看着，也没有问。

那一夜，城头又飘下来丧歌。营里的角声，第一次低低地应了一段。

城上城下，隔着壕墙，给各自的人送行——这一回，像是约好的。
